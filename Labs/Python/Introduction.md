## reStart Python – Cloud9

This repository contains my work from the **reStart Python – Cloud9** training, where I developed foundational programming skills using Python in a cloud-based development environment.

Throughout the exercises, I worked on core concepts such as variables, data types, control structures, functions, and basic scripting. 

Using AWS Cloud9 as the development environment allowed me to write, run, and test code directly in the cloud while becoming familiar with cloud-based tools and workflows.

This project reflects my progress in building programming fundamentals and my ability to apply Python in a practical, cloud-oriented setting.
