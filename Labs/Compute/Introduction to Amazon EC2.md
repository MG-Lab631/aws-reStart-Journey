## Introduction to Amazon EC2

### What is Amazon EC2?

Amazon EC2 (Elastic Compute Cloud) is a cloud service provided by AWS that allows users to create and run virtual servers in the cloud. It provides scalable computing capacity, which makes it easier for developers and organizations to run applications without managing physical hardware.

With EC2, users can launch virtual machines called **instances** that run different operating systems such as Linux or Windows.
