# My Journey in the AWS re/Start Program 

## Introduction

This repository documents my learning journey through the AWS re/Start program.  
The program is designed to help individuals build foundational cloud computing skills and prepare for entry-level careers in the technology industry.

The goal of this repository is to track my progress, share what I learn, and document the hands-on experience I gain while studying cloud computing.

---

## What is the AWS re/Start Program?

AWS re/Start is a full-time skills development and job training program created by Amazon Web Services (AWS).  
It prepares participants for entry-level careers in cloud computing and IT support.

The program combines technical training with professional development and typically runs for about **12 weeks**.

Participants learn core IT and cloud computing concepts while developing practical, job-ready skills.

---

## Technical Skills Covered

During the program, participants learn a variety of important technical topics, including:

- Cloud computing fundamentals
- Core AWS services
- Linux operating systems
- Networking concepts
- Security best practices
- Python scripting basics
- Databases
- Virtualization
- Infrastructure and cloud architecture

The program also prepares students to take the **AWS Certified Cloud Practitioner** certification exam.

---

## Professional Skills Development

In addition to technical training, the program focuses on professional skills such as:

- Interview preparation
- Resume and LinkedIn development
- Communication skills
- Team collaboration
- Problem-solving and critical thinking
- Workplace readiness

These skills help participants successfully transition into real-world technology roles.
