# Security Groups Notes

## What I learned
- Security Groups act as virtual firewalls
- They are stateful (return traffic is automatically allowed)
- You can reference another Security Group instead of IPs

## Rule Pattern
- Web Server → DB Server
- Inbound rule on DB:
  - Source: WebServerSecurityGroup
  - Port: 3306

## Best Practice
Always prefer:
✔ SG-to-SG rules  
❌ Avoid 0.0.0.0/0 unless necessary
